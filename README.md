## How I Contribute
- I prefer small, well-scoped PRs with clear motivation and tests where applicable.
- I triage issues, fix bugs, and improve documentation — open a ticket or a discussion and I’ll do my best to respond.
- If you want to collaborate: open an issue describing the problem or propose a design in a draft PR.

How to contribute to my projects:
1. Fork the repo and create a topic branch.
2. Run tests locally and add tests for new behavior.
3. Open a pull request describing the change and why it helps.
